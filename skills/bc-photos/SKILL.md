## THE GROK PHOTO UPLOAD RULE

When uploading photos to Grok for image generation:
1. Upload BEFORE typing the prompt
2. Number them in upload order (Photo 1, Photo 2, etc.)
3. In the prompt, describe the uploaded photo in precise visual detail
4. Add: **"DO NOT generate new images. Use ONLY the uploaded photo. Apply only color grading on top."**
5. If Grok replaces your photo anyway — add "ABSOLUTE RULE: I uploaded the background photo. Use it exactly as-is. Do not create AI replacements."
