# Knowledge corpus

`source/` contains only deliberately curated business facts approved for customer-facing replies. Do not point ingestion at the whole Desktop, an archive, or private Boxing Center folders.

Each source records its public/private visibility, authority, source URL or provenance, effective date, and optional factual keys. Files under `rules/` shape tone but are never retrieved as business evidence. `indexes/` is generated by `npm run knowledge:index` and is ignored by Git.

When a live offer, schedule, or policy changes, update or replace the relevant source file, verify it, then regenerate the manifest. Conflicting values must be modeled as separate verified sources and escalated rather than silently merged.
